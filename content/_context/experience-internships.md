# Samson Gama's engineering internships, 2014-2016

These internships are historical experience, not Samson's most recent
engineering roles. Entries below are ordered newest first.

At Prizm Media Inc., Software Developer Intern, Dec 2015 - Aug 2016, Samson
reduced response times for frequently used APIs by up to 70% through query
optimization and application-level caching. He developed backend and mobile
features for an AWS-hosted social fitness platform and prototyped machine
learning models using support vector machines and neural networks.

At Ericsson, Software Developer Intern, Sep 2015 - Dec 2015, he developed a
Python plugin for OpenStack Neutron that automated provisioning and lifecycle
management of virtual Ericsson routers.

At Grin Technologies, Software Developer Intern, May 2014 - Aug 2014, he built
web applications for processing and visualizing electric-vehicle telemetry and
administered an AWS-hosted community forum serving 5,000+ daily users through
2020; that administration extended beyond the internship dates.
