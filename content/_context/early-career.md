# What experience preceded Samson's SRE roles?

At Prizm Media Inc., Software Developer Intern, Dec 2015 - Aug 2016, Samson
developed Android and iOS applications for an AWS-hosted fitness platform.
He worked with SVMs and neural networks and reduced frequently used API
response times by up to 90% through query optimization and caching.

At Ericsson, Software Developer Intern, Sep 2015 - Dec 2015, he developed an
OpenStack Neutron plugin in Python to manage virtual Ericsson routers and
troubleshot containerized routers and Mirantis OpenStack test pipelines.

At Grin Technologies, Software Developer Intern, May 2014 - Aug 2014, he built
two web applications for electric-vehicle telemetry and wheel configuration.
He also administered an AWS-hosted electric-vehicle forum serving 5,000+ daily
users through 2020; that administration extended beyond the internship dates.
